# UI icons

The in-game HUD uses selected static React imports from `lucide-react` 1.54.0.
Source: https://lucide.dev/guide/react and https://github.com/lucide-icons/lucide.
License: https://lucide.dev/license; the complete distributed notice is in `LUCIDE-LICENSE.txt`.

| Purpose | Icons |
| --- | --- |
| Character and resources | Star, Coins, TreePine, Gem, HardHat, Users, PackageOpen, Wallet |
| Functional menu | ScrollText, Settings2, Route, Menu |
| Tools | Compass, LayoutGrid, HousePlus, Trash2, Axe, Shovel, Route, BrickWall, Bridge, Pickaxe, Sprout, Wheat |
| Camera and actions | Plus, Minus, RotateCcw, RotateCw, Check, X, HandCoins |
| Connection | Wifi, WifiOff |

Icons are inline SVGs, share a 1.8 stroke width, and keep visible text labels or accessible button names.
The avatar uses initials from the character name; it does not add a new image upload or profile schema.
